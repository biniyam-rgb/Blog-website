┌──────────────────────────────────────────────────────────────────────────────┐
│ COMMON MISTAKES TO AVOID                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

❌ WRONG: Using raw JSON for image upload
   ┌──────────────────────────────────────┐
   │ ● raw                                │
   │ {                                    │
   │     "title": "Test",                 │
   │     "image": "..."  ← Can't do this! │
   │ }                                    │
   └──────────────────────────────────────┘

✅ CORRECT: Using form-data
   ┌──────────────────────────────────────┐
   │ ● form-data                          │
   │ title    | Test        | Text        │
   │ image    | [File]      | File        │
   └──────────────────────────────────────┘


❌ WRONG: Image field type is "Text"
   ┌──────────────────────────────────────┐
   │ image    | test.jpg    | Text ▼      │
   └──────────────────────────────────────┘

✅ CORRECT: Image field type is "File"
   ┌──────────────────────────────────────┐
   │ image    | [Select]    | File ▼      │
   └──────────────────────────────────────┘


❌ WRONG: Token in Headers tab manually
   ┌──────────────────────────────────────┐
   │ Headers Tab:                         │
   │ Authorization | Bearer 1|abc...      │
   └──────────────────────────────────────┘

✅ CORRECT: Token in Authorization tab
   ┌──────────────────────────────────────┐
   │ Authorization Tab:                   │
   │ Type: Bearer Token                   │
   │ Token: 1|abc...                      │
   └──────────────────────────────────────┘


❌ WRONG: Missing /api in URL
   http://localhost:8000/posts

✅ CORRECT: Include /api prefix
   http://localhost:8000/api/posts


┌──────────────────────────────────────────────────────────────────────────────┐
│ VERIFICATION CHECKLIST                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

Before clicking Send, verify:

□ Server is running (php artisan serve)
□ URL is: http://localhost:8000/api/posts
□ Method is: POST
□ Authorization tab has Bearer Token with valid token
□ Body tab is set to: form-data (not raw)
□ title field exists and has value
□ content field exists and has value
□ image field type is: File (not Text)
□ Image file is selected
□ No manual Content-Type header in Headers tab


┌──────────────────────────────────────────────────────────────────────────────┐
│ IF YOU GET HTML INSTEAD OF JSON                                              │
└──────────────────────────────────────────────────────────────────────────────┘

1. Check URL has /api prefix:
   ✅ http://localhost:8000/api/posts
   ❌ http://localhost:8000/posts

2. Clear routes:
   cd backend
   php artisan route:clear
   php artisan config:clear

3. Restart server:
   php artisan serve

4. Try test endpoint first:
   GET http://localhost:8000/api/test
   Should return: {"message": "API is working"}

5. If test works, issue is with authentication
   Get fresh token by logging in again


┌──────────────────────────────────────────────────────────────────────────────┐
│ QUICK TEST SEQUENCE                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

1. Test API:
   GET http://localhost:8000/api/test
   → Should return JSON

2. Login:
   POST http://localhost:8000/api/login
   → Copy token

3. Create post without image:
   POST http://localhost:8000/api/posts
   Body: form-data (title, content only)
   → Should create post

4. Create post with image:
   POST http://localhost:8000/api/posts
   Body: form-data (title, content, image)
   → Should create post with image_url

5. Verify image:
   Copy image_url from response
   Paste in browser
   → Should display image
