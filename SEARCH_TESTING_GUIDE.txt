│ TEST 4: FILTER BY CATEGORY                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

Setup:
1. Create category:
   POST http://localhost:8000/api/categories
   Body: {"name": "Technology"}
   Note the ID (e.g., 1)

2. Create posts with that category:
   POST http://localhost:8000/api/posts
   Body: {
       "title": "Laravel Guide",
       "content": "Content here",
       "category_id": 1
   }

Test:
Method: GET
URL: http://localhost:8000/api/posts?category=1

Expected:
✓ Returns only posts in category 1
✓ Each post has category object
✓ Other categories excluded
