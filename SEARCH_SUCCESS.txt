┌──────────────────────────────────────────────────────────────────────────────┐
│ FEATURES                                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

Search:
  • Searches in title AND content
  • Case-insensitive
  • Partial matching
  • Query: ?search=keyword

Category Filter:
  • Filter by category ID
  • Query: ?category=1
  • Includes category object

Tag Filter:
  • Filter by tag ID
  • Query: ?tag=2
  • Includes tags array

Combined:
  • All filters work together
  • Query: ?search=x&category=1&tag=2

Pagination:
  • 10 posts per page
  • Full metadata
  • Query: ?page=2

Sorting:
  • Latest posts first
  • Ordered by created_at DESC
